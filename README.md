# Потокобезопасная очередь и пул потоков

Курсовой проект по многопоточному программированию на C++17.

## Реализованные классы

- **SafeQueue<T>** – потокобезопасная очередь на основе `std::queue`, `std::mutex` и `std::condition_variable`.
- **ThreadPool** – пул потоков фиксированного размера (количество аппаратных ядер). Принимает задачи через `submit()`, возвращает `std::future` для получения результата.

## Структура

- `safe_queue.hpp` – шаблон очереди
- `thread_pool.hpp` – заголовок пула
- `thread_pool.cpp` – реализация пула
- `main.cpp` – демонстрация
